# CodeAlpha Hangman Game

An interactive Hangman word-guessing game developed using
Python, Flask, HTML, CSS and JavaScript.

## Features

- Random words from multiple categories
- Interactive QWERTY keyboard
- Physical keyboard support
- One hint per round
- Next Word / Skip feature
- Winning points system
- Games Won and Games Played counters
- Six incorrect guesses allowed
- Visual Hangman drawing
- Dark Mode and Light Mode
- Remembers selected theme
- Responsive design

## Requirements

- Python 3
- Flask

## Installation

Install Flask:

    python -m pip install flask

## Run the Project

    python app.py

Open this address in your browser:

    http://127.0.0.1:5000

## Scoring

Players earn up to 100 points per win.

Each incorrect guess reduces the possible score by 10 points.

Skipped or lost rounds award no points.
